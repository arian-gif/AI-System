Generation, one token at a time

The prompt (dim background) plus everything generated so far (blue background). Under each token is the model's top guess for the NEXT token: green if it matches what actually comes next, red if not. The rightmost token has no "next" yet - that's the one about to be generated. Click any token to inspect it below. Note: because of the causal mask, a token's prediction only depends on what comes before it, so the prompt's predictions never change as generation continues - only new tokens get added to the right.

What each layer outputs

One picture per stage: the embedding + position, then the output of each of the 12 blocks. Every row is one token in the sequence and every column is one of its 768 numbers (blue = negative, orange = positive). The white box is the token you clicked. Watch how the representation changes layer to layer, and how new rows appear as tokens are generated.

Inside one block: attention and neurons

Pick a block. Left: every attention head, row = the token doing the looking, column = the token it looks at, brighter = more attention (triangular, since a token can't look ahead). Right: the 3072 neurons in that block's feed-forward layer, reshaped into a grid, showing how strongly each one fires for the token about to be generated - this is the most literal "lighting up" view of the model.
